# Avisos de Software de Terceros / Third-Party Software Notices

Este proyecto se originó como un fork del repositorio de código abierto de **Suresh Beekhani** bajo la Licencia MIT. Las porciones de código original que puedan subsistir están sujetas a los términos de dicha licencia MIT.

Desde el fork, el proyecto ha sido modificado y extendido sustancialmente por **Marlon Baez Mendez** para incorporar funcionalidades avanzadas y robustez de nivel empresarial, incluyendo:
- Sistema multi-agente con 7 agentes especialistas y debate adversarial mediante el agente Devil's Advocate.
- Orquestación dinámica y concurrente de 12 fuentes públicas con circuit breaker.
- Pool de API keys de LLMs con rotación inteligente, auto-exhaustión y recuperación.
- Sistema de pagos e integración con Stripe, Coinbase Commerce y NOWPayments.
- Directorio de inversión bidireccional seguro para fundadores e inversores.
